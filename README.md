# DineSafeViz

![DineSafeViz home page](docs/img/root-readme/dsv-home-1.png)

A dockerized web app that visualizes data from Toronto Public Health's food
safety and inspection program, DineSafe.

## Tech stack

[Well documented](docs/ref/arch.md) and built with a decent
[devops](docs/ref/devops.md) toolchain.

## Features

See a full list of inspection results.

![Inspection results page](docs/img/root-readme/inspec-1.png)

---

View a stats breakdown of the inspection results in the DSV Analytics
dashboard. Specify your own date range. Over 26 years of data!

![DSV Analytics dashboard](docs/img/root-readme/dsv-dash-1.png)

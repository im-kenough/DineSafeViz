# Homelab Kubernetes Deployment — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deploy DineSafeViz on a 6-node kubeadm K8s cluster running on Proxmox VMs, provisioned with Terraform and configured with Ansible.

**Architecture:** Terraform creates 6 Ubuntu 24.04 VMs (3 masters, 3 workers) on Proxmox via cloud-init templates. Ansible bootstraps a kubeadm cluster with Flannel CNI and Longhorn storage. K8s manifests deploy the same 4 services (Flask, PostgreSQL, Grafana, init-grafana) currently running in Docker Compose, with images pulled from ghcr.io.

**Tech Stack:** Terraform (bpg/proxmox provider), Ansible (vault for secrets), kubeadm, Flannel, Longhorn, GitHub Actions (image build/push to ghcr.io)

**Spec:** `docs/superpowers/specs/2026-05-01-homelab-k8s-design.md`

- [ ] **Step 2: Create main.tf**

```hcl
# infra/terraform/main.tf

terraform {
  required_version = ">= 1.5.0"
  required_providers {
    proxmox = {
      source  = "bpg/proxmox"
      version = ">= 0.66.0"
    }
  }
}

provider "proxmox" {
  endpoint = var.proxmox_api_url
  username = var.proxmox_user
  password = var.proxmox_password
  insecure = true
}

resource "proxmox_virtual_environment_vm" "k8s_node" {
  count     = length(var.nodes)
  name      = var.nodes[count.index].name
  node_name = var.proxmox_node

  clone {
    vm_id = var.template_id
  }

  cpu {
    cores = var.nodes[count.index].cpu
  }

  memory {
    dedicated = var.nodes[count.index].memory
  }

  agent {
    enabled = true
  }

  disk {
    datastore_id = "local-lvm"
    interface     = "scsi0"
    size          = var.disk_size
  }

  network_device {
    bridge = "vmbr0"
  }

  initialization {
    ip_config {
      ipv4 {
        address = "${var.nodes[count.index].ip}/24"
        gateway = var.gateway
      }
    }

    dns {
      servers = [var.dns_server]
    }

    user_account {
      username = "ubuntu"
      keys     = [var.ssh_public_key]
    }
  }

  lifecycle {
    ignore_changes = [initialization]
  }
}
```

### Task 5: Ansible Common Role

**Files:**
- Create: `infra/ansible/roles/common/tasks/main.yml`
- Create: `infra/ansible/roles/common/handlers/main.yml`

This role runs on all 6 nodes: disables swap, installs containerd and kubeadm.

- [ ] **Step 1: Create roles/common/tasks/main.yml**

```yaml
# infra/ansible/roles/common/tasks/main.yml
---
- name: Disable swap
  command: swapoff -a
  changed_when: true

- name: Remove swap from fstab
  lineinfile:
    path: /etc/fstab
    regexp: '\sswap\s'
    state: absent

- name: Load required kernel modules
  modprobe:
    name: "{{ item }}"
    state: present
  loop:
    - overlay
    - br_netfilter

- name: Persist kernel modules across reboots
  copy:
    dest: /etc/modules-load.d/k8s.conf
    content: |
      overlay
      br_netfilter

- name: Set sysctl params for K8s networking
  sysctl:
    name: "{{ item.key }}"
    value: "{{ item.value }}"
    sysctl_file: /etc/sysctl.d/k8s.conf
    reload: true
  loop:
    - { key: "net.bridge.bridge-nf-call-iptables", value: "1" }
    - { key: "net.bridge.bridge-nf-call-ip6tables", value: "1" }
    - { key: "net.ipv4.ip_forward", value: "1" }

- name: Install apt dependencies
  apt:
    name:
      - apt-transport-https
      - ca-certificates
      - curl
      - gnupg
    state: present
    update_cache: true

- name: Install containerd
  apt:
    name: containerd
    state: present

- name: Create containerd config directory
  file:
    path: /etc/containerd
    state: directory

- name: Generate default containerd config
  shell: containerd config default > /etc/containerd/config.toml
  changed_when: true

- name: Enable SystemdCgroup in containerd
  replace:
    path: /etc/containerd/config.toml
    regexp: 'SystemdCgroup = false'
    replace: 'SystemdCgroup = true'
  notify: Restart containerd

- name: Enable and start containerd
  systemd:
    name: containerd
    enabled: true
    state: started

- name: Add Kubernetes apt signing key
  shell: |
    curl -fsSL {{ k8s_apt_key_url }} | gpg --dearmor -o /etc/apt/keyrings/kubernetes-apt-keyring.gpg
  args:
    creates: /etc/apt/keyrings/kubernetes-apt-keyring.gpg

- name: Create keyrings directory
  file:
    path: /etc/apt/keyrings
    state: directory

- name: Add Kubernetes apt repository
  copy:
    dest: /etc/apt/sources.list.d/kubernetes.list
    content: |
      deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] {{ k8s_apt_repo }} /

- name: Install kubeadm, kubelet, and kubectl
  apt:
    name:
      - kubeadm
      - kubelet
      - kubectl
    state: present
    update_cache: true

- name: Hold kubeadm, kubelet, kubectl at current version
  dpkg_selections:
    name: "{{ item }}"
    selection: hold
  loop:
    - kubeadm
    - kubelet
    - kubectl

- name: Enable kubelet service
  systemd:
    name: kubelet
    enabled: true

- name: Install Longhorn prerequisites
  apt:
    name:
      - open-iscsi
      - nfs-common
    state: present

- name: Enable and start iscsid
  systemd:
    name: iscsid
    enabled: true
    state: started
```

### Task 6: Ansible Master Role

**Files:**
- Create: `infra/ansible/roles/master/tasks/main.yml`

Initializes kubeadm on the first master, joins the other two masters to the control plane.

- [ ] **Step 1: Create roles/master/tasks/main.yml**

```yaml
# infra/ansible/roles/master/tasks/main.yml
---
# --- First master: kubeadm init ---

- name: Check if cluster is already initialized
  stat:
    path: /etc/kubernetes/admin.conf
  register: kubeadm_init_check

- name: Initialize cluster on first master
  command: >
    kubeadm init
    --control-plane-endpoint={{ control_plane_endpoint }}
    --pod-network-cidr={{ pod_network_cidr }}
    --upload-certs
  register: kubeadm_init_output
  when:
    - inventory_hostname == groups['masters'][0]
    - not kubeadm_init_check.stat.exists

- name: Create .kube directory
  file:
    path: /home/ubuntu/.kube
    state: directory
    owner: ubuntu
    group: ubuntu

- name: Copy admin kubeconfig
  copy:
    src: /etc/kubernetes/admin.conf
    dest: /home/ubuntu/.kube/config
    remote_src: true
    owner: ubuntu
    group: ubuntu
    mode: "0600"
  when: inventory_hostname == groups['masters'][0]

# --- Generate join commands ---

- name: Generate certificate key
  shell: kubeadm init phase upload-certs --upload-certs 2>/dev/null | tail -1
  register: cert_key
  when: inventory_hostname == groups['masters'][0]
  changed_when: false

- name: Generate join command
  command: kubeadm token create --print-join-command
  register: join_command
  when: inventory_hostname == groups['masters'][0]
  changed_when: false

- name: Set join command fact
  set_fact:
    k8s_join_command: "{{ hostvars[groups['masters'][0]].join_command.stdout }}"
    k8s_cert_key: "{{ hostvars[groups['masters'][0]].cert_key.stdout }}"

# --- Other masters: join control plane ---

- name: Join other masters to control plane
  command: >
    {{ k8s_join_command }}
    --control-plane
    --certificate-key {{ k8s_cert_key }}
  when:
    - inventory_hostname != groups['masters'][0]
    - not kubeadm_init_check.stat.exists

- name: Create .kube directory on other masters
  file:
    path: /home/ubuntu/.kube
    state: directory
    owner: ubuntu
    group: ubuntu
  when: inventory_hostname != groups['masters'][0]

- name: Copy admin kubeconfig on other masters
  copy:
    src: /etc/kubernetes/admin.conf
    dest: /home/ubuntu/.kube/config
    remote_src: true
    owner: ubuntu
    group: ubuntu
    mode: "0600"
  when:
    - inventory_hostname != groups['masters'][0]
    - kubeadm_init_check.stat.exists or not kubeadm_init_check.stat.exists
```

### Task 8: Ansible Addons Role

**Files:**
- Create: `infra/ansible/roles/addons/tasks/main.yml`

Installs Flannel, Longhorn, creates namespace, secrets, and imagePullSecret. Runs only on the first master.

- [ ] **Step 1: Create roles/addons/tasks/main.yml**

```yaml
# infra/ansible/roles/addons/tasks/main.yml
---
- name: Apply Flannel CNI
  become: false
  command: kubectl apply -f {{ flannel_manifest_url }}
  changed_when: true

- name: Wait for Flannel pods to be ready
  become: false
  shell: kubectl -n kube-flannel get pods -l app=flannel -o jsonpath='{.items[*].status.phase}' | tr ' ' '\n' | sort -u
  register: flannel_status
  until: flannel_status.stdout == "Running"
  retries: 30
  delay: 10
  changed_when: false

- name: Install Longhorn
  become: false
  command: kubectl apply -f {{ longhorn_manifest_url }}
  changed_when: true

- name: Wait for Longhorn to be ready
  become: false
  shell: kubectl -n longhorn-system get pods --no-headers | grep -v Running | grep -v Completed | wc -l
  register: longhorn_pending
  until: longhorn_pending.stdout | int == 0
  retries: 60
  delay: 10
  changed_when: false

- name: Create application namespace
  become: false
  command: kubectl create namespace {{ app_namespace }}
  register: ns_result
  changed_when: ns_result.rc == 0
  failed_when: ns_result.rc != 0 and 'AlreadyExists' not in ns_result.stderr

- name: Create database secret
  become: false
  command: >
    kubectl create secret generic db-credentials
    --namespace={{ app_namespace }}
    --from-literal=DB_USER={{ vault_db_user }}
    --from-literal=DB_PASSWORD={{ vault_db_password }}
    --from-literal=DB_NAME={{ vault_db_name }}
  register: db_secret_result
  changed_when: db_secret_result.rc == 0
  failed_when: db_secret_result.rc != 0 and 'AlreadyExists' not in db_secret_result.stderr

- name: Create Grafana secret
  become: false
  command: >
    kubectl create secret generic grafana-credentials
    --namespace={{ app_namespace }}
    --from-literal=GF_ADMIN_USER={{ vault_gf_admin_user }}
    --from-literal=GF_ADMIN_PASSWORD={{ vault_gf_admin_password }}
  register: gf_secret_result
  changed_when: gf_secret_result.rc == 0
  failed_when: gf_secret_result.rc != 0 and 'AlreadyExists' not in gf_secret_result.stderr

- name: Create ghcr.io image pull secret
  become: false
  command: >
    kubectl create secret docker-registry ghcr-pull-secret
    --namespace={{ app_namespace }}
    --docker-server=ghcr.io
    --docker-username={{ vault_ghcr_username }}
```

- [ ] **Step 1: Create .github/workflows/docker-publish.yml**

```yaml
# .github/workflows/docker-publish.yml
name: Build and Push Docker Images

on:
  push:
    tags:
      - 'v*'

env:
  REGISTRY: ghcr.io

jobs:
  build-and-push:
    runs-on: ubuntu-latest
    permissions:
      contents: read
      packages: write

    strategy:
      matrix:
        include:
          - image: dsv-web
            context: ./src/dsv-app
            dockerfile: ./src/dsv-app/Dockerfile
          - image: dsv-db
            context: ./src/dsv-db
            dockerfile: ./src/dsv-db/Dockerfile

    steps:
      - uses: actions/checkout@v4

      - name: Log in to GitHub Container Registry
        uses: docker/login-action@v3
        with:
          registry: ${{ env.REGISTRY }}
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}

      - name: Extract metadata
        id: meta
        uses: docker/metadata-action@v5
        with:
          images: ${{ env.REGISTRY }}/${{ github.repository_owner }}/${{ matrix.image }}
          tags: |
            type=semver,pattern={{version}}
            type=raw,value=latest

      - name: Build and push
        uses: docker/build-push-action@v6
        with:
          context: ${{ matrix.context }}
          file: ${{ matrix.dockerfile }}
          push: true
          tags: ${{ steps.meta.outputs.tags }}
          labels: ${{ steps.meta.outputs.labels }}
```

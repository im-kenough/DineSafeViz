# v0.3.0 Infrastructure as Code — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a layered golden image pipeline (Packer + Ansible) with Terraform provisioning and Ansible deployment to run DineSafeViz on a single Proxmox VM.

**Architecture:** Three Packer templates (ubuntu-base → ubuntu-docker → dsv-app) built with Ansible provisioners. Terraform clones the dsv-app template to create the VM. An Ansible deploy playbook SSHs in, clones the repo, templates `.env` from Ansible Vault, and runs `docker compose up`. A Makefile orchestrates all operations.

**Tech Stack:** Packer (proxmox-clone builder), Ansible (roles, vault), Terraform (bpg/proxmox provider), Docker CE, Ubuntu 24.04 LTS

**Spec:** `docs/superpowers/specs/2026-05-10-iac-design.md`

Follows the official Docker apt repository install method:

```yaml
# infra/ansible/roles/docker/tasks/main.yml
---
# --- Docker CE Installation (official apt repository method) ---
# Ref: https://docs.docker.com/engine/install/ubuntu/#install-using-the-repository

- name: Install prerequisites for Docker apt repository
  apt:
    name:
      - ca-certificates
      - curl
    state: present
    update_cache: true

- name: Create keyrings directory
  file:
    path: /etc/apt/keyrings
    state: directory
    mode: "0755"

- name: Add Docker official GPG key
  shell: |
    curl -fsSL https://download.docker.com/linux/ubuntu/gpg \
      -o /etc/apt/keyrings/docker.asc
    chmod a+r /etc/apt/keyrings/docker.asc
  args:
    creates: /etc/apt/keyrings/docker.asc

- name: Add Docker apt repository
  shell: |
    echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] \
      https://download.docker.com/linux/ubuntu \
      $(. /etc/os-release && echo "${VERSION_CODENAME}") stable" \
      > /etc/apt/sources.list.d/docker.list
  args:
    creates: /etc/apt/sources.list.d/docker.list

- name: Update apt cache after adding Docker repo
  apt:
    update_cache: true

- name: Install Docker CE packages
  apt:
    name:
      - docker-ce
      - docker-ce-cli
      - containerd.io
      - docker-buildx-plugin
      - docker-compose-plugin
    state: present

# --- Post-install: run Docker without sudo ---
# Ref: https://docs.docker.com/engine/install/linux-postinstall/#manage-docker-as-a-non-root-user

- name: Add service account to docker group
  user:
    name: "{{ service_account }}"
    groups: docker
    append: true

# --- Start on boot with systemd ---

- name: Enable Docker service on boot
  systemd:
    name: docker
    enabled: true
    state: started

- name: Enable containerd service on boot
  systemd:
    name: containerd
    enabled: true
    state: started

# --- Docker daemon configuration ---

- name: Deploy Docker daemon config
  template:
    src: daemon.json.j2
    dest: /etc/docker/daemon.json
    owner: root
    group: root
    mode: "0644"

# --- Firewall rules ---
```

### Task 12: Render-tfvars Script

**Files:**
- Create: `infra/scripts/render-tfvars.py`

This script reads decrypted Ansible Vault YAML from stdin and writes
HCL-formatted `terraform.tfvars` to stdout.

- [ ] **Step 1: Create render-tfvars.py**

```python
#!/usr/bin/env python3
"""Read decrypted Ansible Vault YAML from stdin, write terraform.tfvars to stdout.

Usage:
    ansible-vault view ansible/vault/secrets.yml --ask-vault-pass | python3 scripts/render-tfvars.py
"""

import sys
import yaml


# Map vault keys to Terraform variable names
VAULT_TO_TF = {
    "vault_proxmox_api_token_id": "proxmox_api_token_id",
    "vault_proxmox_api_token_secret": "proxmox_api_token_secret",
}


def main():
    data = yaml.safe_load(sys.stdin)
    if not data:
        print("Error: no data read from stdin", file=sys.stderr)
        sys.exit(1)

    for vault_key, tf_key in VAULT_TO_TF.items():
        value = data.get(vault_key)
        if value is None:
            print(f"Warning: '{vault_key}' not found in vault", file=sys.stderr)
            continue
        # Escape backslashes and quotes for HCL string
        escaped = str(value).replace("\\", "\\\\").replace('"', '\\"')
        print(f'{tf_key} = "{escaped}"')


if __name__ == "__main__":
    main()
```

```makefile
# infra/Makefile
#
# Orchestrates all IaC operations for DineSafeViz.
# Run targets from the infra/ directory: cd infra && make <target>
#
# Prerequisites: Packer, Terraform, Ansible, Python 3 with PyYAML
# Secrets: stored in ansible/vault/secrets.yml (Ansible Vault encrypted)

SHELL := /bin/bash
.DEFAULT_GOAL := help

ANSIBLE_DIR := ansible
TERRAFORM_DIR := terraform
PACKER_DIR := packer
VAULT_FILE := $(ANSIBLE_DIR)/vault/secrets.yml

# --- Image Pipeline ---

.PHONY: bake-base
bake-base: ## Build ubuntu-base template (Layer 1)
	cd $(PACKER_DIR) && \
	ansible-vault view ../$(VAULT_FILE) --ask-vault-pass \
		| python3 ../scripts/render-pkrvars.py > variables.pkrvars.hcl && \
	packer init ubuntu-base.pkr.hcl && \
	packer build -var-file=variables.pkrvars.hcl ubuntu-base.pkr.hcl; \
	rm -f variables.pkrvars.hcl

.PHONY: bake-docker
bake-docker: ## Build ubuntu-docker template (Layer 2, requires Layer 1)
	cd $(PACKER_DIR) && \
	ansible-vault view ../$(VAULT_FILE) --ask-vault-pass \
		| python3 ../scripts/render-pkrvars.py > variables.pkrvars.hcl && \
	packer init ubuntu-docker.pkr.hcl && \
	packer build -var-file=variables.pkrvars.hcl ubuntu-docker.pkr.hcl; \
	rm -f variables.pkrvars.hcl

.PHONY: bake-dsv-app
bake-dsv-app: ## Build dsv-app template (Layer 3, requires Layer 2)
	cd $(PACKER_DIR) && \
	ansible-vault view ../$(VAULT_FILE) --ask-vault-pass \
		| python3 ../scripts/render-pkrvars.py > variables.pkrvars.hcl && \
	packer init dsv-app.pkr.hcl && \
	packer build -var-file=variables.pkrvars.hcl dsv-app.pkr.hcl; \
	rm -f variables.pkrvars.hcl

.PHONY: bake-all
bake-all: bake-base bake-docker bake-dsv-app ## Build all image layers in order

# --- VM Provisioning ---

.PHONY: provision-vm
provision-vm: ## Provision VM from dsv-app template via Terraform
	ansible-vault view $(VAULT_FILE) --ask-vault-pass \
		| python3 scripts/render-tfvars.py > $(TERRAFORM_DIR)/terraform.tfvars
	cd $(TERRAFORM_DIR) && terraform init && terraform apply
	@rm -f $(TERRAFORM_DIR)/terraform.tfvars

.PHONY: destroy-vm
destroy-vm: ## Destroy the VM via Terraform
	ansible-vault view $(VAULT_FILE) --ask-vault-pass \
		| python3 scripts/render-tfvars.py > $(TERRAFORM_DIR)/terraform.tfvars
	cd $(TERRAFORM_DIR) && terraform destroy
	@rm -f $(TERRAFORM_DIR)/terraform.tfvars

# --- App Deployment ---

.PHONY: deploy-app
deploy-app: ## Deploy app: clone repo, template .env, docker compose up
	cd $(ANSIBLE_DIR) && ansible-playbook playbooks/deploy-dsv.yml --ask-vault-pass

.PHONY: destroy-app
destroy-app: ## Destroy app: docker compose down -v, remove repo (full wipe)
	cd $(ANSIBLE_DIR) && ansible-playbook playbooks/destroy-dsv.yml --ask-vault-pass

.PHONY: destroy-app-keep-data
destroy-app-keep-data: ## Destroy app but keep Docker volumes
	cd $(ANSIBLE_DIR) && ansible-playbook playbooks/destroy-dsv.yml --ask-vault-pass -e "keep_data=true"

.PHONY: redeploy-app
redeploy-app: destroy-app deploy-app ## Full wipe and redeploy

.PHONY: redeploy-app-keep-data
redeploy-app-keep-data: destroy-app-keep-data deploy-app ## Redeploy, keeping Docker volumes

# --- Convenience ---

.PHONY: up
```

```python
#!/usr/bin/env python3
"""Read decrypted Ansible Vault YAML from stdin, write Packer .pkrvars.hcl to stdout.

Usage:
    ansible-vault view ansible/vault/secrets.yml --ask-vault-pass | python3 scripts/render-pkrvars.py
"""

import sys
import yaml


# Map vault keys to Packer variable names
VAULT_TO_PACKER = {
    "vault_packer_api_token_id": "proxmox_api_token_id",
    "vault_packer_api_token_secret": "proxmox_api_token_secret",
}


def main():
    data = yaml.safe_load(sys.stdin)
    if not data:
        print("Error: no data read from stdin", file=sys.stderr)
        sys.exit(1)

    for vault_key, packer_key in VAULT_TO_PACKER.items():
        value = data.get(vault_key)
        if value is None:
            print(f"Warning: '{vault_key}' not found in vault", file=sys.stderr)
            continue
        escaped = str(value).replace("\\", "\\\\").replace('"', '\\"')
        print(f'{packer_key} = "{escaped}"')


if __name__ == "__main__":
    main()
```

```
## Technology Choices

## Image Pipeline

### Why Layered Images?

Each layer adds one concern. When Docker releases a new version, only the
docker layer (and its children) need rebuilding — the base layer stays
unchanged. When K8s comes later, ubuntu-base and ubuntu-docker are reused
directly.

### Layer Details

**Layer 1: ubuntu-base (template 9100)**

Minimal hardened Ubuntu 24.04 server. Reusable across all VM types.

- Service account (`adm-ubuntu`) with SSH key-only auth
- Security: UFW firewall, fail2ban, disabled root login, disabled password
  auth, unattended security upgrades
- Common packages: curl, wget, git, jq, htop, vim
- System: NTP, timezone (America/Toronto), DNS (10.0.20.1)

Rebuild cadence: monthly or after Ubuntu security advisories.

**Layer 2: ubuntu-docker (template 9101)**

Docker-ready VM. Base for any containerized workload.

- Docker CE installed via the official apt repository method
- `adm-ubuntu` can run Docker without sudo
- Docker and containerd enabled on boot via systemd
- Docker daemon configured (log rotation)
- UFW: ports 5000 and 3000 open

Rebuild cadence: on Docker major releases or base layer updates.

**Layer 3: dsv-app (template 9102)**

Application identity and credentials.

- Hostname: yyz-app-dsv01
- Static IP: 10.0.20.80
- GitHub deploy key for repo cloning
- App directory created (`/home/adm-ubuntu/app/`)

Rebuild cadence: on base layer changes or GitHub deploy key rotation.
```
